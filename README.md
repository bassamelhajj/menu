# BENOVA — Crepes & Juices · QR Menu App

منيو رقمي لـ **BENOVA** مبني بـ **Vite + React + TailwindCSS v4 + React Three Fiber + Framer Motion**.

## تشغيل المشروع

```bash
npm install      # أول مرة فقط
npm run dev      # تطوير — http://localhost:5173
npm run build    # نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
npm run lint     # فحص الكود
```

## 🔐 الدخول والإعدادات الحساسة

المصادقة الآن **على السيرفر**، وليس داخل المتصفح:

- كلمة سر الأدمن تُتحقق داخل Vercel Function عبر `scrypt`.
- الجلسة تُحفظ في كوكي `HttpOnly` + `SameSite=Strict` + `Secure` على HTTPS.
- المتصفح لا يستلم كلمة السر ولا بصمتها ولا مفتاح الجلسة.
- لا توجد أي كلمة سر مكتوبة داخل الكود أو `content.json`.

### 1) محلياً

```bash
cp .env.example .env.local
npm run secret                         # مفتاح جلسة عشوائي
npm run hash -- "عبارة-مرور-طويلة"     # بصمة scrypt
```

املأ `.env.local`:

```dotenv
ADMIN_USERNAME=admin@benova.com
ADMIN_PASSWORD_HASH=scrypt$...
ADMIN_SESSION_SECRET=<المفتاح-العشوائي>
```

ثم:

```bash
npm run dev
```

`npm run dev` و`npm run preview` يشغّلان نفس API الأدمن محلياً من خلال Vite،
لذلك يمكنك تجربة الدخول قبل النشر.

### 2) على Vercel

أضف المتغيرات الثلاثة في:

**Project → Settings → Environment Variables**

```dotenv
ADMIN_USERNAME=admin@benova.com
ADMIN_PASSWORD_HASH=scrypt$...
ADMIN_SESSION_SECRET=<مفتاح-طويل-وعشوائي>
```

> ⚠️ لا تضع أي بادئة `VITE_` على هذه القيم. متغيرات `VITE_*` تُبنى داخل
> ملفات العميل وتصبح عامة. هذه القيم تبقى على السيرفر فقط.

### 3) تغيير كلمة السر

لا يمكن تغيير كلمة السر من المتصفح بشكل آمن بدون قاعدة بيانات. الطريقة
الآمنة:

1. شغّل `npm run hash -- "كلمة السر الجديدة"`.
2. على Vercel: حدّث `ADMIN_PASSWORD_HASH` ثم أعد النشر.
3. محلياً: حدّث `.env.local` ثم أعد تشغيل `npm run dev`.

### ملاحظة مهمة عن حسابات الزبائن

حسابات الزبائن الحالية محلية داخل المتصفح (`localStorage`) وليست مصادقة
سيرفر حقيقية. لا تصلح لبيانات زبائن حقيقية على دومين عام. للاستخدام التجاري
الكامل، انقلها إلى قاعدة بيانات ومصادقة خلفية (مثل Supabase أو Neon).

### لوحة التحكم

افتح `/#/admin` ثم سجّل الدخول. الجلسة تنتهي تلقائياً بعد 8 ساعات أو عند
تسجيل الخروج. لا تعتمد على إخفاء الزر فقط — الخادم يتحقق من الكوكي في كل
طلب.

## 📦 النشر

الموقع ثابت بالكامل. بعد التعديل من لوحة التحكم:

1. تبويب **النشر** → تنزيل `content.json`.
2. ضعه في `public/content.json`.
3. ارفع الموقع (أو أعد نشر Vercel).

`content.json` يحتوي بيانات المتجر العامة فقط. لا يحتوي كلمات سر، زبائن، طلبات،
أو إيميلات آراء غير منشورة.

## 🗂️ الملفات المهمة

| الملف | الوظيفة |
|---|---|
| `src/store/ContentContext.jsx` | مصدر البيانات + CRUD + النشر والاستيراد |
| `src/store/AppContext.jsx` | السلة، المفضلة، اللغة، العملة، الثيم، الطلبات |
| `src/data/settings.js` | القيم العامة الافتراضية (بدون أسرار) |
| `src/data/menu.js` | الأقسام والأصناف والإضافات |
| `src/lib/env.js` | إعدادات عامة للمتصفح (قفل المنيو فقط) |
| `src/lib/auth.js` | SHA-256 لأدوات الواجهة + أدوات التطبيع |
| `src/lib/adminApi.js` | استدعاء API تسجيل دخول/جلسة/خروج الأدمن |
| `server/adminAuth.js` | التحقق من كلمة السر + توقيع جلسة HttpOnly |
| `api/admin/*` | Vercel Functions: login / session / logout |
| `vercel.json` | إعدادات البناء ورؤوس الأمان (CSP, HSTS…) |
| `src/pages/admin/*` | تبويبات لوحة التحكم |
| `src/index.css` | ألوان BENOVA والثيم الداكن |
| `public/brand/` | شعار BENOVA |
| `public/menu/` | صور الأقسام وملف المنيو PDF |

## ✅ المزايا

- منيو تفاعلي مع بحث، أقسام، مفضلة، سلة، وإتمام طلب عبر واتساب.
- معرض ثلاثي الأبعاد وكتاب منيو قابل للتقليب مع تنزيل PDF.
- لوحة تحكم كاملة: منتجات، أقسام، إضافات، طلبات، زبائن، آراء، صفحات، توصيل، ونشر.
- عروض فردية وعرض عام، سعر صرف قابل للتعديل، وثيم فاتح/داكن.
- عربي/إنجليزي مع دعم RTL/LTR.
- بناء إنتاجي بدون أسرار أو بيانات حساسة.
