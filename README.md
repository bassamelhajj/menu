# BENOVA — Crepes & Juices · QR Menu App

منيو رقمي لـ **BENOVA** مبني بـ **Vite + React + TailwindCSS v4 + React Three Fiber + Framer Motion**.

## تشغيل المشروع

```bash
npm install      # أول مرة فقط
npm run dev      # تطوير — http://localhost:5173
npm run build    # نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
npm run lint     # فحص الكود
```

## 🔐 الدخول والإعدادات الحساسة

لا توجد كلمات سر داخل الكود أو `content.json`. بيانات الدخول تُقرأ من متغيرات البيئة
عبر `import.meta.env`، وتُخزَّن كبصمة **SHA-256** وليس كنص صريح.

1. انسخ الملف النموذجي:

   ```bash
   cp .env.example .env.local
   ```

2. أنشئ بصمة كلمة السر:

   ```bash
   npm run hash -- "كلمة-سر-قوية"
   ```

3. املأ `.env.local`:

   ```dotenv
   VITE_ADMIN_USERNAME=owner
   VITE_ADMIN_PASSWORD_SHA256=<البصمة-من-الخطوة-السابقة>
   VITE_SITE_PASSWORD_SHA256=   # اختياري: قفل المنيو العام
   ```

4. أعد تشغيل `npm run dev`. على **Vercel** أضف نفس المتغيرات في
   *Project Settings → Environment Variables* ثم أعد النشر.

> `VITE_*` تُبنى داخل ملفات العميل. لذلك نخزّن البصمة فقط، ومع ذلك تبقى حماية
> واجهة مناسبة لموقع ثابت — وليست بديلاً عن مصادقة سيرفر حقيقية. استخدم عبارة
> مرور طويلة، وفعّل المصادقة على السيرفر إذا احتجت أماناً كاملاً.

### الدخول المحلي المؤقت (وضع التطوير)

عند تشغيل `npm run dev` فقط، يتم تجاوز الهاش ومتغيرات البيئة:

- اسم المستخدم: `admin@benova.com`
- كلمة السر: القيمة الموجودة في `TEMP_LOCAL_ADMIN` داخل `src/lib/env.js`.
- هذا الوضع لا يُبنى في نسخة الإنتاج، لأن `import.meta.env.DEV` تصبح `false` عند `vite build`.
- لإلغائه نهائياً: احذف كتلة `TEMP_LOCAL_ADMIN` من `src/lib/env.js`.

### لوحة التحكم

افتح `/#/admin` ثم سجّل الدخول. في الإنتاج استخدم اسم المستخدم وكلمة السر
المضبوطين في متغيرات البيئة.

يمكن تغيير كلمة سر الأدمن من **الإعدادات → الأمان والوصول → تغيير كلمة سر
الأدمن**. تُحفظ كلمة السر الجديدة كبصمة SHA-256 في `localStorage` على هذا
المتصفح فقط، ويُستخدم زر **استعادة الافتراضية** للرجوع إلى كلمة السر الأصلية.
لتغييرها على كل الأجهزة، حدّث `VITE_ADMIN_PASSWORD_SHA256` في الاستضافة.

## 📦 النشر

الموقع ثابت بالكامل. بعد التعديل من لوحة التحكم:

1. تبويب **النشر** → تنزيل `content.json`.
2. ضعه في `public/content.json`.
3. ارفع الموقع (أو أعد نشر Vercel).

`content.json` يحتوي بيانات المتجر العامة فقط. لا يحتوي كلمات سر، زبائن، طلبات،
أو إيميلات آراء غير منشورة.

## 🗂️ الملفات المهمة

| الملف | الوظيفة |
|---|---|
| `src/store/ContentContext.jsx` | مصدر البيانات + CRUD + النشر والاستيراد |
| `src/store/AppContext.jsx` | السلة، المفضلة، اللغة، العملة، الثيم، الطلبات |
| `src/data/settings.js` | القيم العامة الافتراضية (بدون أسرار) |
| `src/data/menu.js` | الأقسام والأصناف والإضافات |
| `src/lib/env.js` | قراءة متغيرات البيئة والتحقق من البصمات |
| `src/lib/auth.js` | SHA-256 ومقارنة آمنة لكلمات السر |
| `src/pages/admin/*` | تبويبات لوحة التحكم |
| `src/index.css` | ألوان BENOVA والثيم الداكن |
| `public/brand/` | شعار BENOVA |
| `public/menu/` | صور الأقسام وملف المنيو PDF |

## ✅ المزايا

- منيو تفاعلي مع بحث، أقسام، مفضلة، سلة، وإتمام طلب عبر واتساب.
- معرض ثلاثي الأبعاد وكتاب منيو قابل للتقليب مع تنزيل PDF.
- لوحة تحكم كاملة: منتجات، أقسام، إضافات، طلبات، زبائن، آراء، صفحات، توصيل، ونشر.
- عروض فردية وعرض عام، سعر صرف قابل للتعديل، وثيم فاتح/داكن.
- عربي/إنجليزي مع دعم RTL/LTR.
- بناء إنتاجي بدون أسرار أو بيانات حساسة.
